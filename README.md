My bigger Python projects are stored within the subfolders of this repository:
* Environments details my exploration with web scrapers (Selenium to be exact), writing Windows terminal GUI applications using Curses, REST APIs in the context of scraping information on videos from my YouTube channel and websites in general and creating mobile apps in Python
* FunctionalProgramming details me teaching myself how to use Haskell in the functional programming paradigm to provide me with more approaches to finding solutions to mathematical problems.
* Tkinter is another software which can be used to create less visually-appealing apps (can better handle desktop applications, not just the mobile apps of PyQt5) in Python
* Flask_website is the prototype website for students to post their queries of school topics and questions online for others to answer, fitted with a ranking system, a pomodoro timer for self-studying and a to-do page for storing all tasks to be completed.
* Neural network contains the barebone code to develop a neural network written from scratch (well, using only the numpy library for arrays and array calculations). I've included in it multiple activation functions for more versality in future applications - one of which will be a recreation of the neural network made by the Cambridge Psychometrics Centre during their Facebook scandal.

The rest of the unfoldered programs are smaller, mini-projects I used to self-teach Python and usage of CSV files.
